seo-toolkit

Live demo of the Python tools in the repository. Everything runs the same code as the CLI, behind small serverless functions. Nothing you paste is stored.

Write Q&A as Markdown (## Question then the answer), or load the built-in bank of general SEO questions. Output is a sanitized, linted FAQPage JSON-LD with the matching visible HTML.

Paste a page's HTML. Checks JSON syntax, required properties, @id references, and that every FAQ question is actually visible on the page.

One keyword per line. Keywords are grouped by TF-IDF similarity and never merged across search intent.

Paste a Search Console export with columns query,page,clicks,impressions,ctr,position.

Paste daily clicks per page with columns date,page,clicks. A page is flagged when the latest window dropped over 20% and the fitted trend is negative.

The site crawler and log analyzer are CLI-only on purpose: a public "enter any URL" crawler is an SSRF risk, and logs shouldn't be uploaded to a demo. Sample data is synthetic. Source on GitHub.
